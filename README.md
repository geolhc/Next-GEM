# Next GEM — GitHub Pages Edition

A static, GitHub-only version of the Next GEM pitch website. No installation, build command, Cloudflare account or server is required.

## Upload and publish

1. Create a new GitHub repository named `next-gem`.
2. Choose **Public** if everyone with the final link should be able to open it.
3. Do not initialise the repository with another README, `.gitignore` or licence.
4. Upload **all files inside this folder** directly to the repository root.
5. Open **Settings → Pages** in the repository.
6. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
7. Select branch `main`, folder `/ (root)`, then click **Save**.
8. Wait around 1–3 minutes and refresh the Pages settings screen.

Your shareable website link will normally be:

`https://YOUR-USERNAME.github.io/next-gem/`

## Important

- Upload the extracted files, not the ZIP itself.
- `index.html` must be visible on the repository's main page, not inside an extra folder.
- If the repository is private, GitHub plan and organisation policies may affect public Pages access. A public repository is the simplest option for a link that teammates can open directly.
- This concept prototype is for internal discussion. Validate any speed, eligibility, compliance or service statements before external/customer-facing use.

## Main files

- `index.html` — all website content
- `styles.css` — responsive design
- `script.js` — interactive five-minute pitch mode
- `favicon.svg` — browser icon
